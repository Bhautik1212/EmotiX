# 11. MULTIMODAL SEVERITY FUSION ENGINE

Build a dedicated, testable fusion engine.

Implement:

POST /api/v1/assessments/{assessment_id}/finalize

GET /api/v1/assessments/{assessment_id}/result

The engine must combine the available outputs from:

1. Behavioural assessment.
2. Chat text analysis.
3. Facial emotion analysis.
4. Voice emotion analysis.

The website describes an overall score on a 0–10 scale with four risk bands:

- Low.
- Moderate.
- High.
- Critical.

Preserve this interface while documenting the limitations of the prototype.

Do not combine unrelated probability scores blindly.

First, define and document a justified mapping from each module's output to a common scale.

Create a configurable weighting system.

Example starting weights for a software prototype:

- Behaviour: 35%.
- Chat: 30%.
- Face: 15%.
- Voice: 20%.

These weights are illustrative configuration values, not clinically validated parameters.

Do not present them as research findings or scientifically established weights.

The fusion service must:

1. Accept the completed assessment's actual results.
2. Validate the origin and ownership of every result.
3. Map available results onto the documented common scale.
4. Apply the configured weights.
5. Handle missing modalities correctly.
6. Calculate a score between 0 and 10.
7. Return the risk band using documented thresholds.
8. Explain the main contributing factors.
9. Record the algorithm version.
10. Save the final result.
11. Prevent duplicate finalization or handle retries safely.
12. Provide recommendations appropriate to the prototype's intended use.

If a modality is missing, renormalize the weights over the available, valid modalities and disclose the reduced coverage.

If no valid modality is available, return an appropriate validation error rather than inventing a score.

Do not interpret a missing result as a zero-risk result.

Define and test the risk-band boundaries, including exact boundary values.

Treat crisis safety signals separately from the ordinary weighted score. A possible crisis must not be hidden by a low average score.

Do not use the overall score to diagnose depression, anxiety, or any other medical condition.

Make it clear in the interface that the score is an experimental wellbeing-screening indicator and not a validated clinical prediction.

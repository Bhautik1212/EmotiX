Project report

EmotiX – Smart Mental Health Counselling System Using Multimodal AI

Review 2 summary: problem, objectives, architecture, models and results.

Problem statement

  • Mental health screening depends on self-reporting and manual observation, which is subjective and hard to access.
  • Most digital tools analyse a single input, only text, only face or only voice, so the picture is incomplete.
  • Existing tools rarely give one unified severity score or detect crisis situations early.

Objectives

  • Behaviour analysis from lifestyle data: sleep, stress, blood pressure, steps.
  • Facial emotion recognition with a CNN, voice emotion with MFCC + SVM, chat analysis with NLP and an LLM counsellor.
  • Weighted severity fusion into Low, Moderate, High and Critical risk, with crisis detection and emergency routing.
  • Interactive dashboard, secure login, PDF reports and cloud deployment.

Model accuracy

Test-set accuracy from the Review 2 evaluation.

Key findings

  • Face: the Custom CNN beats MobileNetV2 by about 13 points in accuracy.
  • Voice: MFCC + SVM reaches 93.6% accuracy; the Log-Mel CNN stays near chance and needs more tuning.
  • The face model is strongest on happy and surprise, weakest on fear.
  • Class imbalance is real: disgust has 436 images against 7,215 for happy.

Challenges and next steps

  • GPU and training-time limits: started with FER2013, CK+, KDEF and JAFFE are next.
  • Similar voice emotions and noise: targeted tuning and noise handling.
  • LLM tone, cost and rate limits: prompt refinement and usage monitoring.
  • Class imbalance: class weights and more data.

Tools and technologies

  • Frontend: React 19, Vite, Tailwind CSS, Framer Motion, Recharts, Three.js
  • Backend: FastAPI, Uvicorn, SQLAlchemy, SQLite, JWT, Google OAuth
  • AI / ML: TensorFlow / Keras, Scikit-learn, OpenCV, Librosa
  • NLP: VADER, TextBlob, Gemini via OpenRouter
  • Deployment: Vercel and Hugging Face Spaces (Docker)
